Arabize 4.8.4 Code Audit

نطاق العمل:
- لا تغيير في تصميم الواجهة.
- لا إضافة أو تعديل للترجمات.
- لا تغيير للخط العربي.
- لا تغيير لمسار الاستخدام: فحص، تثبيت، إزالة.

الإصلاحات:
1. تثبيت traceback الحقيقي لأخطاء خيط العمل مع Python 3.14.
2. إعادة فحص الواجهة بعد انتهاء أي عملية لاستعادة حالات الأزرار الصحيحة.
3. تصحيح مسار اكتشاف النسخة الاحتياطية داخل الواجهة.
4. فحص حدود مداخل TAB قبل القراءة أو الكتابة.
5. استبدال assert الحرجة بفحوص RuntimeError تعمل حتى مع python -O.
6. التحقق من وجود وصحة كل ملفات بيانات التشغيل قبل تعديل اللعبة.
7. التحقق من بنية ملفات JSON الأساسية.
8. منع التثبيت فوق ملفات غير موثقة إذا كانت النسخة الاحتياطية قديمة.
9. إضافة استعادة تلقائية إذا فشل التثبيت بعد بدء الكتابة.
10. إضافة فحص بعد التثبيت لمواضع وأحجام النص والخط داخل TAB وARC.
11. تحسين فحص ملف تشغيل اللعبة وصحة النسخة الاحتياطية.
12. إزالة مراجع تايلاندية قديمة من تعليقات المحرك النشط.
